# Scripts utiles Asmozia

Petits outils partagés par [Asmozia](https://www.asmozia.com), intégrateur Odoo, pour faciliter le quotidien des utilisateurs d'Odoo. Chaque dossier contient ses scripts et leur mode d'emploi.

| Dossier | Contenu |
|---|---|
| [tampermonkey](tampermonkey/) | Scripts utilisateur pour l'extension Tampermonkey (Chrome, Edge) |

N'installez que des scripts dont vous connaissez la source : un script agit sur les pages où il s'exécute. Ceux de ce dépôt sont lisibles en entier avant installation.
